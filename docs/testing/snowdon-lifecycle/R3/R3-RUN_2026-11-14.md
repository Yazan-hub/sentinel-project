## Findings from the drill

All fixed (7703cf14, e06a7105), each with a test, and each seen fixed on screen.

- **F-R3-1**: the Quality tab said only "1 problem" for the new checks. It now names the first two problems and counts the rest ("2 problems: …; and 1 more").
- **F-R3-2**: the LOIN grid was wider than the pane, so the "Why" column sat behind a sideways scroll. The grid now fits the pane.
- **F-R3-3**: right after a publish on a project with no review chain the document said "Needs a review: the ids standard was reinstalled", for an install made before the publish. A publish now counts as the point since which changes are listed.
- **F-R3-4**: picking a start on a document whose office template had been removed said "This document was published or archived meanwhile…". The bridge answered a 409, which the workspace reads as a status change; it now answers a 422 with the right words.
