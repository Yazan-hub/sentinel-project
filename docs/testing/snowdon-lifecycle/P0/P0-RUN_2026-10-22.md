## 2026-10-24: BEP version 1 published (step 8), with the wrong label

As gmail (lead) in the local app: "→ shared" (ledger #3505, `transitioned` wip→shared, 01:55:30 UTC), then "Publish…" (ledger #3506, `published`, 01:55:56 UTC). `bim_document_versions` holds version 1, `published_by` yazanhijazeen32@gmail.com, **label "v1"**, not the requested "Pre-appointment (tender)". The document status is published.

- **F-LC-6 (the version label can never be given in the platform).** "Publish…" asks for the label with the browser's `prompt()` dialog (`docs-panel.ts:706`; the READINESS publish at `:866` is the same). The That Open platform runs the app in an iframe whose sandbox is `allow-scripts allow-same-origin allow-forms allow-popups allow-popups-to-escape-sandbox allow-downloads`, with no `allow-modals`, so `prompt()` returns null at once and the question is never shown; `prompt(...) || ""` sends an empty label and the bridge falls back to `v1`. The local app has the same wrapper, so this hits every publish from Documents, published or local. Four browser `confirm()` calls share the fate (in this frame `confirm()` returns false, so the guarded action silently never runs): `clash-panel.ts:564` (propose deleting copies), `data-feed-panel.ts:117` (revoke a feed key), `docs-panel.ts:767` (overwrite after a 409), `files-panel.ts:456` (retire an evidence file). Checked by a dialog test in a plain top-level tab: there `prompt()` does open and blocks the page (and browser automation cannot type into it), so the difference is the sandbox. Versions are append-only (no relabel route), so v1 stays "v1"; the intended label is recorded here. The roadmap's P0 done criterion ("version 1 labelled Pre-appointment (tender)") is therefore not met, and P1 needs a labelled BEP v2 "Confirmed", so under the hybrid rule (decision 13) this is a small defect that blocks the next phase: replace the two prompts with an in-page label field and the four confirms with an in-page yes/no, on a branch with tests, then publish v2 with the right label.
