Sentinel ▸ Standards & Build ▸ Model from Drawings

Cuts a mass at each storey level into typed walls, floors and a roof, filed for review.

How to use it

  1. Select a mass.
  2. Click Model from Drawings ▸ 2c · Shell a Mass.
  3. Read the plan (No = read-only).
  4. File the changeset and apply it in Review AI Proposals.

Good to know

  • A storey that leans or is not one straight-edged loop goes to a person.
