Review Flag

Sentinel ▸ Coordinate

One-time setup that creates the ZZZ_ReviewStatus parameter on views, sheets, levels and grids.

How to use it

  1. Open the central model as coordinator.
  2. Click Coordinate ▸ Review Flag.
  3. Create a Browser Organization scheme that groups by ZZZ_ReviewStatus.

Good to know

  • Run it once per model; Change Requests uses this flag.
