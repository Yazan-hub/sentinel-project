Clash Register

Sentinel ▸ Coordinate ▸ Clash

Read-only view of the team-wide clash register recorded on the web.

How to use it

  1. Click Coordinate ▸ Clash ▸ Clash Register.
  2. Filter by status to follow each clash's lifecycle.
  3. Use the web app to change a clash's status.

Good to know

  • The model must be bound to a web project (Project Setup).
