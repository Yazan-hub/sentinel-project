BCF Issues

Sentinel ▸ Coordinate

Reviews coordination issues raised on the web and lets you fix referee issues in place.

How to use it

  1. Click Coordinate ▸ BCF Issues.
  2. Double-click an issue to zoom to its element and camera.
  3. For an IDS issue, open Fix in Revit and enter the values.
  4. Press Check, then Apply ticked; the issue resolves only when every element passes.

Good to know

  • If the bridge is down, a fix reads applied, NOT verified and the issue is not changed.
