MEP Type Check

Sentinel ▸ Validate

Checks ducts, pipes, cable trays and conduits against the project's type catalogue.

How to use it

  1. Click Validate ▸ MEP Type Check.
  2. Review mismatched type names and system types.
  3. Optionally save the BCF topic file.

Good to know

  • Reads only; no size check and no retype.
  • One ledger row per check.
