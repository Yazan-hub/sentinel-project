Ingest Docs

Sentinel ▸ Standards & Build ▸ Standards

Reads standards documents with a local LLM into a reviewable standards pack.

How to use it

  1. Start Ollama on this PC.
  2. Click Standards ▸ Ingest Docs and pick PDF, text or CSV files.
  3. Review the extracted worksets and parameters, then save the pack.

Good to know

  • Requires Ollama; nothing leaves the PC.
