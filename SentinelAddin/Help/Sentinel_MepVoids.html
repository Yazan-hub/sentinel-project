MEP Openings

Sentinel ▸ Validate

Finds linked MEP and structure intersections and places tracked provision-for-void families.

How to use it

  1. Load the MEP link.
  2. Click Validate ▸ MEP Openings.
  3. Review candidates; nearby ones merge within 150 mm.
  4. Place voids, or export the set as BCF.

Good to know

  • Re-runs relocate moved voids, flag deleted ones Orphaned and never touch status Cut.
