Rule Set

Sentinel ▸ Validate

Shows the ruleset this document is judged by, with its source and sha.

How to use it

  1. Click Validate ▸ Rule Set.
  2. Browse the rule cards: mode, token patterns, messages, whitelists.
  3. Check the source line to see where the ruleset came from.

Good to know

  • Rulesets are installed on the web project or its office, never on this PC.
