Builds LOD 200 geometry from a 2D DWG import using the project's layers standard.

How to use it

  1. Import the DWG plan.
  2. Click Model from Drawings ▸ 2 · Ghost Builder.
  3. Map CAD layers; suggestions are never pre-ticked.
  4. File the changeset and apply it in Review AI Proposals.

Good to know

  • Walls are typed by the project's guideline and type catalogue.
