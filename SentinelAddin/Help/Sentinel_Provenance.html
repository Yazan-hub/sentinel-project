5 · Provenance

Sentinel ▸ Standards & Build ▸ Model from Drawings

Shows where an element came from: source, file sha, CAD layer, rule, approver and ledger row.

How to use it

  1. Select an element.
  2. Click Model from Drawings ▸ 5 · Provenance.
  3. Read its provenance stamp.

Good to know

  • A copied stamp reads copied, not placed by Sentinel.
  • Reads only.
