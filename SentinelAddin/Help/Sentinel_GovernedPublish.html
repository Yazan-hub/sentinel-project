Governed Publish

Sentinel ▸ Publish

The one publish path: export IFC, run the delivery gate, adjudicate, and register a version on pass.

How to use it

  1. Bind the model to its web project (Project Setup).
  2. Click Publish ▸ Governed Publish.
  3. Wait for export, gate and adjudication.
  4. Read the dialog: the version, its verdict and both ledger rows.

Good to know

  • A reject uploads nothing; each failing requirement opens as a BCF issue.
  • A registered version is wip until a lead shares it on the web.
