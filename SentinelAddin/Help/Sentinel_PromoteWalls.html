Sentinel ▸ Standards & Build ▸ Model from Drawings

Promotes walls, floors, roofs, ceilings, doors and windows to DD by the guideline and LOD matrix.

How to use it

  1. Click Model from Drawings ▸ 4 · Promote (DD).
  2. Read the plan (No = read-only).
  3. Review ambiguous elements sent to a person.
  4. File the changesets, one per storey.

Good to know

  • No type is ever created; only loaded catalogue types are used.
