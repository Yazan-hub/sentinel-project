# Sentinel — Install (Revit 2021–2027)

## One-time prerequisite
.NET SDK 8 or newer. In PowerShell:

    winget install Microsoft.DotNet.SDK.8

## Build + install (one command)
From this folder (`sentinel-project\SentinelAddin`):

    powershell -ExecutionPolicy Bypass -File .\build.ps1

The script auto-detects which Revit versions are installed (2021–2027),
builds the matching flavor for each (net48 for 2021–2024, .NET 8 for
2025–2027), and copies the DLLs + `Sentinel.addin` into
`%AppData%\Autodesk\Revit\Addins\<year>`.

Restart Revit → accept the "Load Sentinel" prompt → a **Sentinel** ribbon
tab appears with Show Panel / Scan Now / Rule Set.

## Manual single-version build

    dotnet build .\Sentinel.csproj -c Release -p:RevitVersion=2023 -p:DeployToRevit=true

## Uninstall
Delete `%AppData%\Autodesk\Revit\Addins\<year>\Sentinel.addin` and the
`Sentinel` subfolder.

## Version compatibility notes
- All API differences are isolated in `Compat.cs` (`ElementId` long/int, etc.).
- `#if REVIT2024_OR_GREATER`-style defines are generated by the csproj.
- Rulesets are cached at `%AppData%\Sentinel\ruleset.json` (user) and
  `%ProgramData%\Sentinel\ruleset.json` (deployed office default).
