IFC Gate

Group of two IFC deliverable checks: Pre-Flight before you export, and Delivery Gate to certify the IFC file.

IFC Gate is a drop-down on the Validate panel holding two tools that belong together. IFC Pre-Flight audits the Revit model before export, so you can fix missing IFC mappings and missing required properties while it is still cheap. IFC Delivery Gate exports (or opens) an IFC file and certifies it against the delivery contract.

Both judge against the delivery contract installed on the model's web project, or on its office. The contract names the IFC schema to export and the required properties and property sets. If no contract is installed, nothing is judged, and the tools say so instead of reporting a pass.

A typical sequence: run IFC Pre-Flight and fix what it lists, run IFC Delivery Gate to certify the export, and upload to the common data environment only when the gate does not say FAIL. The one-step governed route that also registers a version is Governed Publish.

Before you start

  • See the individual tools: IFC Pre-Flight and IFC Delivery Gate.

How to use it

  1. On the Sentinel tab, in the Validate panel, open the "IFC Gate" drop-down.
  2. Choose "IFC Pre-Flight" or "IFC Delivery Gate".

Related tools

  • IFC Pre-Flight — Audits the model before IFC export for missing 'Export to IFC As' mappings and for the properties the delivery contract requires.
  • IFC Delivery Gate — Exports the model to IFC (or opens an existing IFC) and certifies it against the delivery contract, recording the verdict on the project ledger.
  • Governed Publish — Publishes the whole model to the web project through the one governed path: IFC export, delivery gate, IDS and naming check, then a registered version on the ledger.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
