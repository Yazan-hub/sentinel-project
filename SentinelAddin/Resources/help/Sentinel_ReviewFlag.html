Review Flag

One-time project setup: creates the ZZZ_ReviewStatus flag parameter on Views, Sheets, Levels and Grids so pending changes can be grouped in the Project Browser.

Review Flag adds a text project parameter named ZZZ_ReviewStatus to the model and binds it to Views, Sheets, Levels and Grids. Sentinel writes into this parameter to flag items that have a pending change request, so you can see them at a glance. The parameter is not user-editable (its description reads "Do not edit manually").

Run it once per project (or per template). Revit's API cannot create a Project Browser organisation scheme, so after running it you make one final manual step: View tab ▸ User Interface ▸ Browser Organization ▸ New scheme grouping by ZZZ_ReviewStatus. Pending items then appear in their own group in the browser.

Only a coordinator can run it: a lead or owner of the model's web project.

Before you start

  • An open document.
  • The model must be bound to a web project (Sentinel ▸ Project Setup) and you must be a lead or owner on it (sign in via Sentinel ▸ Sign in). Otherwise a dialog says "Only a lead or owner of the web project can run project setup — <reason>."
  • The document must not already contain the parameter.

How to use it

  1. Sign in as a lead or owner and make sure the model is bound to its web project.
  2. On the Sentinel tab, in the Coordinate panel, click "Review Flag".
  3. Read the confirmation dialog: "'ZZZ_ReviewStatus' created and bound to Views, Sheets, Levels and Grids."
  4. Do the final manual step it describes: View tab ▸ User Interface ▸ Browser Organization ▸ New scheme grouping by ZZZ_ReviewStatus.

What you get

  • A project parameter ZZZ_ReviewStatus (text, instance, in the Identity Data group, bound to Views, Sheets, Levels and Grids) is added in one Revit transaction named "Sentinel: Setup workflow parameter".
  • Sentinel uses a temporary shared parameter file in the Windows temp folder for the definition and puts your own shared parameter file setting back afterwards.
  • If the parameter already exists you get "'ZZZ_ReviewStatus' already exists in this project." and nothing is changed.

Tips and limits

The Browser Organization scheme must be created by hand once; it is best done in the project template so every project inherits it.
If you are not a lead or owner, ask one to run it.
The "signed out" reason appears if you are not signed in; sign in first.
It is one Revit transaction and can be undone, but undoing it removes the flag Sentinel uses for pending requests.

Related tools

  • Change Requests — Lists the change requests waiting for a coordinator and lets a lead or owner approve or reject each one.
  • Show Panel — Opens the dockable Sentinel pane, which shows the model's live rule results, the project's journey from the web, and the Doctor log.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
  • Sign in — Signs you in with your Sentinel account so everything Revit sends to the project carries your name.
