5 · Provenance

Shows where the selected element came from: Sentinel's provenance stamp in plain words.

Provenance reads the stamp that Sentinel puts on elements it places or changes (Datum from Drawings, Ghost Builder, Shell a Mass, Promote and others) and describes it in a dialog. It only reads; nothing in the model changes and nothing goes over the network.

The dialog names the element (category, id and name) and then says whether Sentinel placed or changed it, the source, the checksum (sha256) of the source file, the CAD layer, the rule that typed it, the approver, the ledger row of the proposal and the time. A stamp that came along with a copy reads "Copied, not placed by Sentinel" and shows that the lines below belong to the original element.

Before you start

  • A Revit project open.
  • An element to read: select exactly one element before clicking, or pick one when asked.

What you provide

Element
Select one element first. With no selection or several elements selected you pick one at the prompt "Pick an element to read its Sentinel provenance stamp".

How to use it

  1. Select one element in the model.
  2. Click Model from Drawings, then "5 · Provenance". If you did not select exactly one element, pick one when prompted; Esc cancels.
  3. Read the dialog.

What you get

  • A dialog "Sentinel — Provenance" with the stamp. If there is no stamp it says Sentinel did not place or change this element.

Tips and limits

Fields a stamp did not record are said so, for example no source file for an element that came from a drawing already imported in the model, or an approver shown as unsigned (sign in so your name is recorded).
Older stamps read "not recorded" for the newer fields.
Copying an element copies its stamp, so check the first line of the dialog.

Related tools

  • 1 · Datum from Drawings — Reads the levels from a section drawing and the grids from a plan drawing and creates them in the model, so that everything modelled afterwards sits on real heights and a real column grid.
  • 2 · Ghost Builder — Builds LOD 200 Revit geometry (walls, floors, doors, windows and more) from a 2D DWG plan, mapping CAD layers to Revit types by the project's standards, after you review and tick what to build.
  • 4 · Promote (DD) — Promotes the model's walls, floors, roofs, ceilings, doors and windows to design-development types by the office guideline, type catalogue and LOD matrix, filing the changes for review.
  • Review AI Proposals — Lets you review AI-proposed model changes: see the referee's verdict per element, tick what you accept, and apply exactly that to the model in one Undo step.
  • Sign in — Signs you in with your Sentinel account so everything Revit sends to the project carries your name.
