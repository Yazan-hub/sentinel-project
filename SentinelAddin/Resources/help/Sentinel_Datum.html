1 · Datum from Drawings

Reads the levels from a section drawing and the grids from a plan drawing and creates them in the model, so that everything modelled afterwards sits on real heights and a real column grid.

Datum from Drawings is the first step of the chain. It reads a DWG or DXF and finds the level lines and the grid lines on the layers that the project's layers standard names in its datum section. The heights and grid positions are measured straight off the drawing geometry; nothing is estimated and no language model is involved.

You see everything it found before anything is created. A review window lists every level and every grid with a tick box and a name, and for levels an elevation in millimetres from the zero level and a Building Story box. You untick lines that are not really levels or grids (a parapet line, a section mark), type your office's names, and say which level is zero. Only then does it create them.

A level at a height already in the model, or a grid on a line already in it, is kept and not duplicated, so you can run it again on another sheet. Each drawing has its own origin, so read the section for levels and the plan for grids as separate runs. When the run creates something, it also sends a datum row and a build receipt to the project's ledger.

Before you start

  • A Revit project open. It must not be in a design option; if one is being edited the tool stops and asks you to switch to the Main Model.
  • Set the project base point and survey point first, as usual: the drawings are read origin to origin.
  • Drawings to read: either a Ghost source folder set in Project Setup that holds the project's DWG or DXF files, or a DWG already imported into the model. With neither, you get "No drawings to read".
  • A layers standard installed on the project or its office that has a datum section naming the layers for levels and grids. If the guideline cannot be read, the tool refuses rather than guess. If the standard has no datum section, the run finds nothing and lists the layers it saw so you can fix the standard or the drawing.
  • The Ghost source folder must be one this PC accepts; if it does not, the tool stops before reading anything.
  • If the guideline's placement block names a workset for Levels or Grids, the model must have that workset; otherwise the run is refused before anything is created.

What you provide

Drawing list ("Sentinel — Datum: choose ONE drawing")
Shown when a Ghost source folder is set. Pick the one drawing to read, then press "Use selected drawing ▶" (or double-click it). Use the section for levels and the plan for grids; run again for the other.
The drawing's units:
"as the file says" by default. Choose millimetres, centimetres, metres, inches or feet if the drawing's own header is wrong.
Create (tick box)
One per level and grid. Untick anything that is not a real level or grid.
Name
The name the level or grid will get. Type your office's own labels.
±0.00 at:
Which level is the zero of the building. Levels below it read negative.
Elevation (mm from ±0.00)
Editable height of each level.
Building Story
Tick for levels that are storeys. Annotate Views and Promote rely on this.
Runs (mm)
Shown for each grid so you can recognise it. Not editable.

How to use it

  1. Open the project and click Model from Drawings, then "1 · Datum from Drawings".
  2. If a Ghost source folder is set, choose a drawing in the list, set "The drawing's units:" if needed and press "Use selected drawing ▶". If no folder is set, the DWG already imported into the model is read directly.
  3. Wait for the read. If nothing is found you get "Found no level or grid lines" with the layers the drawing holds.
  4. In the review window untick lines that are not levels or grids, rename them, set "±0.00 at:" and the Building Story boxes.
  5. Press "Create ▶". Cancel creates nothing.
  6. Read the result dialog, rename in the Project Browser if needed, and continue with Ghost Builder or Annotate Views.

What you get

  • Levels and grids are created in the model, each stamped with where it came from.
  • A dialog reports how many levels and grids were created, what the placement block did, and any notes. It also suggests Annotate Views as the next step.
  • One datum row and one build receipt are sent to the project's ledger (the pane's log says what the ledger answered).

Tips and limits

Run once per drawing: sheets have different origins.
If "Nothing was created" appears, Revit did not commit; an element it needs may be owned by another user. The model is unchanged.
If the read finds nothing, check the datum section of the layers standard against the actual layer names in the drawing.
The unit setting matters: a drawing in metres read as millimetres gives levels at the wrong heights.

Related tools

  • 2 · Ghost Builder — Builds LOD 200 Revit geometry (walls, floors, doors, windows and more) from a 2D DWG plan, mapping CAD layers to Revit types by the project's standards, after you review and tick what to build.
  • 3 · Annotate Views — Creates the work-in-progress plan views the guideline prescribes for each level, pins levels and grids, and optionally copies view templates and makes sheets with tags.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
  • Standards — A drop-down group for binding a model to its web project, signing in, and building, applying or ingesting office standards.
  • 5 · Provenance — Shows where the selected element came from: Sentinel's provenance stamp in plain words.
