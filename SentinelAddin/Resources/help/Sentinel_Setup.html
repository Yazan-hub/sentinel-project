Project Setup

Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.

Project Setup is where a model is told which web project it belongs to, like picking an ACC or Forma project. The project's ruleset, IDS and naming standard all come from that web project (or its office), so most Sentinel tools refuse to do anything until this is saved.

Settings can be saved at two scopes. "Current project" stores them inside the Revit model (Extensible Storage), so they travel with the model and sync with central to the whole team. "This machine only" stores paths and defaults in %AppData%\Sentinel\config.json for this PC; at machine scope the web project, project code and Doctor option are switched off because they belong to a model.

Saving the web project at project scope also confirms, on this PC, that this model publishes into that project. Until a PC has confirmed the project for a model, Auto-publish and scan posts are paused on that PC (a copy or Save As of a model asks again). After saving, the ruleset for the chosen project is reloaded.

Before you start

  • For project scope, a model must be open; with no model open only machine scope is available.
  • The Sentinel bridge should be running so the project list can load. If it is not, the Web project box is a plain text field and you type the project key (the hint says "Bridge unreachable - type the project key").
  • If you are signed out, the project list may not load ("Signed out - Sentinel > Sign in, or type the project key"). Typing the key still works.

What you provide

Project code (optional - tightens the CDE file-name check, e.g. BDS20268)
Your office's project code. It is saved in upper case and tightens the file-name check against the naming standard. Leave blank if you do not use one.
Web project - where this model publishes
Pick a project from the list, or type its key (for example demo). The list shows each project's name and key, with its office. This is what binds the model.
Ghost source folder (DWGs, specs - drives Datum & Ghost Builder)
A full local folder path where the source DWGs and specifications live; use Browse... to pick it. A share typed as a share path is refused for project scope; use a full path (a mapped drive is fine).
Revit Doctor checkbox
When ticked, Revit straightens slightly off-axis lines in this model using its own fix in every transaction. Off by default; when off, the Doctor only logs the warnings it sees and never removes one. Bound models only.
Save scope
"Current project (Extensible Storage - syncs with central, whole team)" or "This machine only (%AppData%\Sentinel\config.json - paths and defaults; never the web project)".
Save / Cancel
Save writes the settings and closes; Cancel closes without saving.

How to use it

  1. Open the model, then click Sentinel > Standards > Project Setup.
  2. Choose the Web project from the list, or type its key.
  3. Optionally enter the Project code and set the Ghost source folder with Browse....
  4. Leave Save scope on "Current project" to bind the model, then click Save.
  5. The dialog closes; the settings are written to the model and the project's ruleset reloads. If the model has never been saved to a file, save it and run Project Setup > Save again so this PC can confirm the project (the Doctor log says so).

What you get

  • At project scope: the web project key, project code, ghost folder and Doctor option are stored in the model as a Revit change named "Sentinel: Save project settings", and this PC records that it confirmed that project for this model.
  • At machine scope: the ghost source folder is written to %AppData%\Sentinel\config.json, and the dialog shows "Saved as machine default".
  • The Sentinel pane refreshes its ruleset and Next strip for the new project.

Tips and limits

A line under the Web project box says what Save confirms: that this model, on this PC, publishes into the named project.
The footer shows who the bridge will see: "Signed in as ..." or "Signed out"; use Sign in to change it.
A folder that cannot be used from a model (for example a share path rather than a full local path) shows a message and is not saved.
If the Web project hint says the bridge address is refused, the configured bridge address is not allowed and no token is sent to it; fix the Sentinel configuration.
Machine scope never binds a model; if tools say "not bound", save at project scope.

Related tools

  • Sign in — Signs you in with your Sentinel account so everything Revit sends to the project carries your name.
  • Governed Publish — Publishes the whole model to the web project through the one governed path: IFC export, delivery gate, IDS and naming check, then a registered version on the ledger.
  • Apply Standard — Loads a saved standards pack from disk and lets you build it into the open model, the golden-to-blank round trip.
  • 1 · Datum from Drawings — Reads the levels from a section drawing and the grids from a plan drawing and creates them in the model, so that everything modelled afterwards sits on real heights and a real column grid.
  • 2 · Ghost Builder — Builds LOD 200 Revit geometry (walls, floors, doors, windows and more) from a 2D DWG plan, mapping CAD layers to Revit types by the project's standards, after you review and tick what to build.
  • Show Panel — Opens the dockable Sentinel pane, which shows the model's live rule results, the project's journey from the web, and the Doctor log.
