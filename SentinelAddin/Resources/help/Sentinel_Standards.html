Standards

A drop-down group for binding a model to its web project, signing in, and building, applying or ingesting office standards.

The Standards drop-down gathers the setup and standards tools. Project Setup binds the open model to its web project, which is where its ruleset, IDS and naming come from. Sign in attaches your own Sentinel account to everything Revit sends. Build Office System extracts the office standard from a "golden" model, Apply Standard builds a saved standards pack into the open model, and Ingest Docs reads a written standard with a local language model.

Typical order for a new model: Project Setup, then Sign in, then Apply Standard to bring in the office worksets and shared parameters. A standards lead uses Build Office System on the golden template and Ingest Docs on written standards to create packs for the others.

Before you start

  • See the individual tools. Almost everything downstream in the Sentinel tab depends on Project Setup having bound the model to a web project.

How to use it

  1. Click the Standards drop-down arrow under Sentinel > Standards & Build.
  2. Choose Project Setup, Sign in, Build Office System, Apply Standard or Ingest Docs.

Tips and limits

Project Setup and Sign in need no special permission; the build tools change the model and are normally used by the standards lead.

Related tools

  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
  • Sign in — Signs you in with your Sentinel account so everything Revit sends to the project carries your name.
  • Build Office System — Reads the office standard out of the open "golden" model, lets you review and tick it, then builds it into this model and into the project's ruleset.
  • Apply Standard — Loads a saved standards pack from disk and lets you build it into the open model, the golden-to-blank round trip.
  • Ingest Docs — Reads office-standards documents with a local language model and proposes worksets, shared parameters and naming rules for you to review.
  • ROI Dashboard — Shows the web project's ledger counts for delivery gate runs, naming renames and family heals, and prices them if the project has an ROI standard.
