BCF Issues

Shows the coordination issues raised on the web (BCF), jumps Revit to each issue's element and camera, and lets you raise new issues from your Revit selection.

BCF Issues opens a window titled "Sentinel — Coordination Issues (BCF)" listing the open issues of the model's web project. Issues are raised by people who do not use Revit (in the web viewer) and by you, and the list stays live: when someone raises or changes an issue on the web it appears within seconds without pressing anything. Select an issue to read its details: title, type, status, priority, who it is assigned to, due date, labels, author, how many elements it is linked to, the description, the comments and the history.

To act on an issue, double-click it (or press "Zoom to issue (or double-click)"): Revit applies the issue's first saved viewpoint, taking you to the linked element and camera. "Isolate ALL issue elements" isolates every element linked to any open issue in the list. "Issues for my Revit selection" answers the reverse question: select elements in Revit, press it, and the issues those elements belong to are highlighted in the list.

"＋ New issue from my Revit selection" raises an issue from Revit: select the element(s), optionally be in a 3D view so the camera travels with it, and describe the issue in the "Sentinel — New issue" dialog. It lands on the web board linked to those elements.

"Fix in Revit (referee-raised IDS issues only)" is for the issues Sentinel's referee raised itself (their titles read "IDS: … — … (N failing)"). It opens a "Sentinel — Fix in Revit" window where you enter the missing values, have the referee check them, apply them in one Revit transaction and re-check. Evidence is posted on the issue, and it is marked Resolved only when every listed element passes; closing it stays a human decision on the web.

Before you start

  • A document must be open and bound to a web project (Sentinel ▸ Project Setup). Otherwise you get: "This model is not bound to a web project — Sentinel ▸ Project Setup."
  • The Sentinel bridge must be running and reachable. If not, the status line reads "Could not reach the BCF service at <address>" followed by the reason.
  • You should be signed in (Sentinel ▸ Sign in); if the session cannot be used, a dialog or the status line says so in words and the list is not loaded.
  • Fix in Revit also needs the model that the window was opened on to be the active one, and an IDS (requirements spec) installed on the web project or its office to check against; without one, applying is allowed but nothing can be checked, certified or resolved.
  • A new issue needs at least one selected element that has an IFC identity.

What you provide

Issues (list)
Select one issue to read it; select several to isolate or compare. Double-click zooms to the first one.
Revit selection
For "Issues for my Revit selection" and "＋ New issue from my Revit selection": select elements in the model first. For a new issue, working in a 3D view also sends the camera (an isometric view is sent as a 60° perspective); in any other view there is no camera.
Title
New issue dialog. Required; at most 600 characters. "Create issue" stays disabled until there is a title.
Description
New issue dialog. Pre-filled with what you selected (for example how many of each category) and the model name; edit freely.
Type
New issue dialog: Issue, Clash, Fault, Info or Request (default Issue).
Priority
New issue dialog: Low, Normal, High or Critical (default Normal).
Assigned to (e-mail or name)
New issue dialog. Optional.
Due date (optional)
New issue dialog. Optional date picker.
Set all ticked to / Set / Zoom / Untick all / Show only ticked / Check / Apply ticked / Re-check
Fix in Revit window. Tick the rows to fix, type a value per row (or one value in "Set all ticked to" and press "Set"), then Check, Apply ticked, Re-check.

How to use it

  1. On the Sentinel tab, in the Coordinate panel, click "BCF Issues".
  2. Wait for the status line to say how many open issues were found ("Double-click to zoom in Revit."). Press "Refresh" to reload by hand.
  3. Click an issue to read its details. Double-click it to zoom Revit to its element and camera.
  4. To see everything affected, press "Isolate ALL issue elements".
  5. To check whether what you have selected is already reported, select elements in Revit and press "Issues for my Revit selection".
  6. To raise an issue, select the element(s) in Revit (be in a 3D view if you want a camera), press "＋ New issue from my Revit selection", fill in the dialog and press "Create issue". The status line then reports what the bridge answered.
  7. To fix a referee-raised issue, select it and press "Fix in Revit (referee-raised IDS issues only)". In the window, tick the rows, enter values, press "Check" (nothing is written yet), then "Apply ticked", then read the result of the automatic re-check.

What you get

  • Zooming and isolating change only the view; the status line reports what was done.
  • A new issue is created on the web board with the label "revit", status Open, linked to the selected elements; it then appears in the list.
  • Fix in Revit writes the ticked values in a single Revit transaction. After a re-check, an evidence comment is posted on the issue (who fixed it, how many elements now pass, the IDS used and the ledger row). Only when every listed element passes is the status set to Resolved; otherwise the issue stays as it was.
  • Applying and checking add rows to the project's audit ledger.

Tips and limits

"This issue has no viewpoint." means there is nothing for Revit to zoom to.
"Only referee-raised IDS issues can be fixed here." appears for any other kind of issue; the Fix button is greyed out unless the selected issue's title has the IDS form.
"Select the element(s) the issue is about first — nothing was sent." means the selection had no usable elements. "A title, please — nothing was sent." means the title was empty.
"switch back to the model the Issues window was opened on — nothing was sent": the window belongs to the model it was opened in; make that model active again.
In Fix in Revit, a message that the referee response is not conclusive means some elements were missing from the model or the failure list was cut off; nothing is certified in that case.
If the issue names more failing elements than it lists, the unlisted ones are never examined, and the issue stays open until you re-publish to raise a fresh, complete one.
Only one Fix window can be open per issue.
Closing the Issues window closes any open Fix windows and stops the live updates.

Related tools

  • Clash Manager — Detects clashes between linked MEP/IFC models and your native structure, grades them by severity, and lets you open a coloured 3D clash view or export them to BCF.
  • Clash Register — Shows, read-only, the project's team-wide clash register recorded on the web: how many clashes there are, their status counts, and the biggest by volume.
  • Publish — A drop-down group holding Publish Sheets and Publish Views, which send drawing images to the web app outside the governed IFC path.
  • Governed Publish — Publishes the whole model to the web project through the one governed path: IFC export, delivery gate, IDS and naming check, then a registered version on the ledger.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
  • Sign in — Signs you in with your Sentinel account so everything Revit sends to the project carries your name.
