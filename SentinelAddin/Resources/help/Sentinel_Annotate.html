3 · Annotate Views

Creates the work-in-progress plan views the guideline prescribes for each level, pins levels and grids, and optionally copies view templates and makes sheets with tags.

Annotate Views is the third step of the chain. It reads the views section of the office modelling guideline installed on the project or its office and plans the floor plan and ceiling plan views for each level. Each view name comes from the project's view-naming rule, or a fixed WIP name, and is checked against Scan Now's naming rule before anything is created.

A preview window shows everything first. Story levels get the guideline's first floor plan and first ceiling plan entry pre-ticked; other views are listed unticked; a row that cannot be made is greyed with its reason. The same window lists every unpinned level and grid (story levels and grids are pre-ticked) so you can pin them in the same run.

If the guideline has a sheets block, you can also choose one level for which to make sheets and tags: sheets on the guideline's title block with the view placed on them, and tags for categories such as rooms. Those rows are never pre-ticked. If the guideline names view templates the model lacks, you are offered to copy them from an office template file you pick; the file is opened in the background and is never saved or changed.

Before you start

  • A Revit project open with levels in it; with none you are told to run Datum from Drawings first.
  • The project's ruleset must be loaded: run Scan Now once, otherwise the tool refuses because it cannot judge the view names.
  • A guideline with a views section installed on the project or its office. Without it, there is nothing to plan and the tool says so.
  • At least one level should be a Building Story; otherwise no view or level is pre-ticked (unpinned grids still are).
  • For sheets: a sheets block in the guideline and its title block family loaded in the model. For tags: the tag families loaded. Sentinel loads no families; a row that needs a missing family is refused with the family name.
  • The model needs default floor plan and ceiling plan view types.

What you provide

View rows (tick boxes)
Grouped by level. Each shows name, use and template. Tick the views to create.
Pin rows
Unpinned levels and grids to pin. A level or grid that another user owns, or that changed in central, is listed unticked with the reason.
Sheets and tags for:
Choose one level to plan sheets and tags for, or leave it unset. Tick a sheet row to enable its tag rows.
Pick the office template file…
Offered when view templates named by the guideline are missing. Choose an .rte or .rvt file, or "Continue without them".

How to use it

  1. Click Model from Drawings, then "3 · Annotate Views".
  2. If asked about missing view templates, pick the office template file or continue without them.
  3. In "Sentinel — Annotate: views and pins" read the lines at the top, then tick or untick views and pins. Optionally choose a level in "Sheets and tags for:" and tick sheets and tags.
  4. Press "Create ▶". Cancel writes nothing.
  5. Read the result dialog.

What you get

  • Views, pins, copied view templates, sheets with viewports and tags are created in one Undo entry named Annotate views. Each view is made on its own: one that fails is rolled back and named, and the rest are kept.
  • The dialog lists what was created and pinned, what was not created and why, failures and warnings.
  • One annotate row goes to the ledger naming the views and datums the model holds.

Tips and limits

Revit may empty its Undo list after views are named. If Edit ▸ Undo does not list Annotate views, the ledger row is the record of which views to delete and which datums to unpin by hand.
Views already in the model are skipped, not duplicated.
If every ticked row fails, the dialog says nothing was created and the model is as it was.
Scan Now judges the new view names by the same rule, so names that pass here pass there.

Related tools

  • 1 · Datum from Drawings — Reads the levels from a section drawing and the grids from a plan drawing and creates them in the model, so that everything modelled afterwards sits on real heights and a real column grid.
  • Scan Now — Re-reads the ruleset that judges this model and runs a full compliance scan, showing the result in the Sentinel pane.
  • 4 · Promote (DD) — Promotes the model's walls, floors, roofs, ceilings, doors and windows to design-development types by the office guideline, type catalogue and LOD matrix, filing the changes for review.
  • Standards — A drop-down group for binding a model to its web project, signing in, and building, applying or ingesting office standards.
  • Publish Sheets — Renders every Revit sheet to an image and a PDF for the web app's Sheets tab, and proposes each PDF to the project's document register.

Ribbon tooltip

Plan views and pins from the guideline installed on this document's web project (or its office): one preview lists levels × its floor plan and ceiling plan entries, named by the project's View rule (or the fixed WIP_ name) and judged by Scan Now's rule — story levels × the first of each pre-ticked, a refused row says why — and the unpinned levels and grids (story levels and grids pre-ticked). Writes only what you tick, as one Sentinel Undo entry; if Revit empties its Undo list (B31), the annotate ledger row is the record. No guideline installed = nothing to plan.
