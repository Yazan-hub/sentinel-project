Model from Drawings

The Model from Drawings pulldown groups the seven tools that take a project from drawings or photos to a governed Revit model, in the order they are meant to be run.

Model from Drawings is a pulldown, not a command of its own. Its seven entries are numbered in the order of the chain: 1 · Datum from Drawings, 2 · Ghost Builder, 2b · Photo Massing, 2c · Shell a Mass, 3 · Annotate Views, 4 · Promote (DD) and 5 · Provenance. The idea is datum first, then geometry, then views, then promotion to design-development (DD) types, with a stamp on everything Sentinel touches so you can always ask where an element came from.

Datum comes first because everything else hangs on it: real levels and a real grid, measured off your section and plan drawings, mean that walls built afterwards host to real floors and sit on a real column grid. Then you model geometry in one of two ways. Ghost Builder builds LOD 200 geometry from a 2D DWG plan. Photo Massing works from the project's evidence-pack photos instead: it estimates a building envelope (storeys, proportions) that you scale with one known dimension, and files a mass for review. Shell a Mass then turns a mass (yours, or the one Photo Massing made) into typed walls, floors and a roof, one storey at a time.

Annotate Views then creates the work-in-progress plan views, pins the datum and, if the guideline asks for it, makes sheets and tags. Promote (DD) retypes what is in the model to the office's exact DD types. Provenance reads back the stamp on any element.

How the tools are governed: Datum and Ghost Builder show you a review window and write only what you tick. Photo Massing, Shell a Mass and Promote (DD) do not write to the model themselves; they file their proposal as a changeset on the project's web ledger and open Review AI Proposals, where a person ticks and applies it. The standards that drive the chain (the layers standard, the office modelling guideline, the type catalogue, the LOD matrix) are installed on the project's web workspace or on the office. A standard that is not installed is shown as "none", and the tool says so instead of falling back on something else.

Before you start

  • A Revit project open and active (Shell a Mass and Promote (DD) refuse to run in a family document).
  • For the changeset-based tools (Photo Massing, Shell a Mass, Promote (DD)) the model must be bound to a web project: use Project Setup first. Without it they stop with "This model is not bound to a web project".
  • The standards the chain reads must be installed on the project or its office: a layers standard (with a datum section) for Datum and Ghost Builder, a guideline for Ghost Builder, Shell a Mass, Annotate Views and Promote (DD), and a type catalogue for Shell a Mass and Promote (DD).
  • The Sentinel bridge must be running for the tools that file changesets or read the standards.
  • Ghost Builder and Photo Massing use a language or vision model that runs on your own PC (Ollama).

How to use it

  1. Open the Sentinel tab and the Model from Drawings pulldown.
  2. Run 1 · Datum from Drawings to create the levels and grids from your section and plan drawings.
  3. Model the geometry: run 2 · Ghost Builder on a 2D DWG plan, or 2b · Photo Massing on the evidence-pack photos followed by 2c · Shell a Mass. You can use both, and model by hand in between.
  4. Run 3 · Annotate Views to create the plan views (and sheets, if the guideline has them) and to pin the levels and grids.
  5. Run 4 · Promote (DD) to retype walls, floors, roofs, ceilings, doors and windows to the office's DD types and open the result for review.
  6. Use 5 · Provenance at any point to read where a single element came from.

What you get

  • Each tool reports in its own dialog. Datum and Ghost Builder write to the model after you press their own create or build button. Photo Massing, Shell a Mass and Promote (DD) put changesets into Review AI Proposals; nothing is placed until a person applies them.
  • Elements Sentinel places or changes carry a provenance stamp (source, source file, layer, rule, approver, ledger row, time).

Tips and limits

You do not have to run every step. The numbers are the recommended order, not a requirement; for example Annotate Views only needs levels in the model, wherever they came from.
Each tool that writes to the model does so as one Undo entry. Revit sometimes empties its Undo list afterwards; the tool's dialog and the ledger row then tell you what was made.
Sentinel never places into a design option. Switch to the Main Model first.
