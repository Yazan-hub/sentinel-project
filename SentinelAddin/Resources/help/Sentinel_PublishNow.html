Publish

Publishes the model, with the pre-publish check shown first in plain words.

Publish first runs the same check as Check and says in plain words what is left to fix. Open Check goes back to fix them; Publish now exports the model to IFC, checks it against the project's requirements and uploads it if it passes. If it fails, nothing is uploaded and the reason is shown; the full report is under Details.

Before you start

  • A project model open and active.

How to use it

  1. Click Publish.
  2. Read the pre-publish check.
  3. Press Open Check or Publish now.

What you get

  • Published, or Not published with the reason.

Related tools

  • Check — Checks the model against the project standards and groups what to fix.
  • Publish model — Publishes the whole model to the web project through the one publishing path: IFC export, pre-publish check, data requirements and naming check, then a registered version in History.

Ribbon tooltip
