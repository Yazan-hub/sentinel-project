Heal Loaded Families

Scans the model families already in the project, auto-fixes a missing shared parameter and reports what needs a person.

Heal Loaded Families opens each editable, loadable model family in the active project (in-place families and families Revit cannot edit are skipped), runs the same checks as Sanitize .rfa, and sorts each into one of four results: clean, auto-healed, requires human interaction, or failed.

Auto-healing is deliberately narrow. If a family only lacks the required shared parameter, Sentinel adds it and reloads the family into the project. If a family has heavy geometry or nested CAD imports, it is never touched: it goes to the human list with the reason.

Every run is one row on the project's ledger (a family heal), with the counts and the names of the healed, human-needed and failed families, so the clean-up is traceable.

Before you start

  • A project document must be active, with model families loaded.
  • An office code in the model's ruleset is needed for the shared parameter check; without one that check is skipped and nothing is healed for it.
  • Binding to a web project through Project Setup, for the ledger row. An unbound model is healed locally and the report says nothing was sent.

How to use it

  1. Make the project the active document.
  2. On the Sentinel tab, in the Validate panel, open "Family Health" and click "Heal Loaded Families".
  3. Wait. Each family is opened and closed in the background, so a large project takes time.
  4. Read the dialog "Sentinel — Family Auto-Heal".

What you get

  • A dialog with: families scanned, clean, auto-healed (shared parameters injected and reloaded), requires human interaction (geometry or CAD), failed. Up to 12 families that need attention are listed with their notes.
  • Healed families are reloaded into the project.
  • One ledger row for the run. The last line of the dialog says whether it was recorded, not confirmed, not recorded, or not sent because the model is not bound.

Tips and limits

"Requires human interaction" is by design: geometry, CAD and reference fixes are never automated.
The command works on the model that was active when you clicked it, so a heal never lands on whichever model has focus by the time it runs.

Related tools

  • Sanitize .rfa — Audits a family file (.rfa) for heavy geometry, nested CAD, missing shared parameters and unnamed types, and loads it into the project only if it passes.
  • Naming Manager — Reviews family and type names against the office naming rules, proposes compliant names and renames only the rows you tick.
  • ROI Dashboard — Shows the web project's ledger counts for delivery gate runs, naming renames and family heals, and prices them if the project has an ROI standard.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
