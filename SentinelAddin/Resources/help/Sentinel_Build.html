Build

Model from drawings and photos, step by step, in one window.

Build lists the modelling steps in the order they are meant to be run: 1 Levels and grids, 2 Model from drawings (Ghost Builder), 3 Massing from photos (Photo Massing, then Shell a Mass), 4 Annotate views, 5 Promote to DD. Each step says in one sentence what it does, what the model has now (counts of levels, grids, walls, masses and pinned datum) or what it needs, and has a button that opens the same tool as before.

The last line, Where did this come from?, opens Provenance for the selected element.

What is not counted here (the photos on the web, the office guideline, each element's stage) says "not checked here"; the tool itself shows it when it opens.

Before you start

  • A project model open and active.

How to use it

  1. Click Build.
  2. Read the state line of each step.
  3. Press the step's button: its tool opens as it does from Build tools in the slide-out.

What you get

  • The tool you picked runs exactly as from its own button; Build itself changes nothing.

Tips and limits

You do not have to run every step; the numbers are the recommended order.
The numbered tools are also in the slide-out (the arrow under the panel) under Build tools.

Related tools

  • Build tools — Build tools, in the slide-out, holds the seven numbered tools the Build window opens, for people who know them.
  • 1 · Datum from Drawings — Reads the levels from a section drawing and the grids from a plan drawing and creates them in the model, so that everything modelled afterwards sits on real heights and a real column grid.
  • 2 · Ghost Builder — Builds LOD 200 Revit geometry (walls, floors, doors, windows and more) from a 2D DWG plan, mapping CAD layers to Revit types by the project's standards, after you review and tick what to build.
  • 2b · Photo Massing — Estimates a building's storeys and proportions from the project's evidence-pack photos, lets you scale and correct the numbers, and files the missing levels and a mass for review.
  • 2c · Shell a Mass — Turns a selected mass into typed walls, a floor per level and a flat roof, one storey at a time, sent for review as sets of proposed changes.
  • 3 · Annotate Views — Creates the work-in-progress plan views the guideline prescribes for each level, pins levels and grids, and optionally copies view templates and makes sheets with tags.
  • 4 · Promote (DD) — Promotes the model's walls, floors, roofs, ceilings, doors and windows to design-development types by the office guideline, type catalogue and LOD matrix, filing the changes for review.
  • 5 · Provenance — Shows where the selected element came from: Sentinel's provenance stamp in plain words.
