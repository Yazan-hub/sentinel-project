Clash Manager

Detects clashes between linked MEP/IFC models and your native structure, grades them by severity, and lets you open a coloured 3D clash view or export them to BCF.

Clash Manager compares the elements of every loaded Revit link and IFC link against the open model's walls, floors, structural framing and structural columns. On the link side it looks at ducts, pipes, cable trays and conduits, plus the generic shapes an IFC link brings in. Each overlap is graded: Hard (the two solids share more than a litre of volume), Medium (the solids intersect with a smaller shared volume) and Soft (the bounding boxes overlap but the solids do not, a proximity clash). Detection is read-only; it never changes the model.

When clashes are found, a window titled "Sentinel — Clash Manager" lists them worst first, with the columns "Severity", "Host element", "Category", "Host ID", "MEP element", "Link", "Location" and "Vol m³". The header counts clashes by severity and appends the Federation Gate status for the model's web project, so you can see whether the project's data gate has passed (PASS, FAIL, NOT RUN or NOT CHECKABLE), how many models were read, and whether it is stale.

From the window you can select a clash and press "Show element" to select and zoom to the host element, press "Create 3D clash view" to build a dedicated 3D view with a section box around the clashes and the host elements coloured by their worst severity, or press "Export BCF" to write the clashes to a BCF file for BIMcollab, Solibri or Navisworks. If you select rows, the view and the export use only those rows; with nothing selected they use all clashes.

Before you start

  • An open project document with at least one loaded Revit link or IFC link that contains MEP elements or IFC shapes. With no walls, floors, structural framing or columns in the open model, or no matching link content, there is nothing to find.
  • Links must be loaded (not unloaded) in the model; an unloaded link is skipped.
  • To see the Federation Gate status the model must be bound to a web project (otherwise the header says "Federation Gate: not checked" with the Project Setup hint) and the bridge must be reachable (otherwise "Federation Gate: bridge unreachable").
  • Large models with many link elements can take a while because every candidate pair is checked in turn.

What you provide

Clash rows (selection)
Select one or more rows (Ctrl/Shift-click) to restrict "Create 3D clash view" and "Export BCF" to them; select none to use all.
Show element
Acts on the single selected row.
Choose BCF output folder (file name is auto-generated)
A save dialog that appears when you press "Export BCF". Pick the folder; the file name is generated for you.

How to use it

  1. On the Sentinel tab, in the Coordinate panel, open the "Clash" drop-down and click "Clash Manager".
  2. Wait for detection to finish; if nothing is found a dialog says "No clashes found between linked MEP/IFC elements and native structure." with the Federation Gate line, and the command ends.
  3. Read the header counts and the Federation Gate status; review the list (coloured Hard, Medium, Soft).
  4. Select a row and press "Show element" to see it in the model.
  5. Select the rows you care about (or none for all) and press "Create 3D clash view" to get a new 3D view that Revit switches to.
  6. Press "Export BCF", choose the output folder, and note the path in the "✓ Exported" confirmation.

What you get

  • Clash detection writes nothing to the model.
  • "Create 3D clash view" adds a 3D view named "CO_MEP-CLASH_<date>_<time>" with a section box around the clashes (1 m margin) and Fine detail, and colours the host elements red, orange or yellow by their worst severity. Sentinel tries to file it under the browser group "05_COORDINATION & QA/QC" and "05.3_MEP COORDINATION" using your office's browser parameters; if those parameters are not present it falls back to the Coordination discipline and the Doctor log in the Sentinel pane says so. A confirmation dialog names the view.
  • "Export BCF" writes one BCF issue titled "MEP clashes (<count>)", type Clash, status Active, authored by the signed-in person, whose description lists up to the first 25 clashes and which links up to 100 of the host elements. A dialog shows the file path, or the error if it failed.

Tips and limits

Link elements cannot be coloured individually in the host view; the host element is coloured and the section box brings you to the link element.
If the solid intersection cannot be computed for a pair, that clash stays graded Soft.
A Soft clash only means the bounding boxes overlap; check it before acting.
If the Federation Gate says NOT RUN or FAIL, run or fix it on the web before relying on the clash result.
The clash list is a snapshot from the moment you pressed the button; reopen Clash Manager after changing the model or the links.
To track clashes as a team, raise them as issues (BCF Issues) or run the web clash and read it back with Clash Register.

Related tools

  • Clash Register — Shows, read-only, the project's team-wide clash register recorded on the web: how many clashes there are, their status counts, and the biggest by volume.
  • BCF Issues — Shows the coordination issues raised on the web (BCF), jumps Revit to each issue's element and camera, and lets you raise new issues from your Revit selection.
  • MEP Openings — Finds where linked MEP crosses native walls, floors and structural framing and offers to place tracked provision-for-void markers or export a BCF.
  • MEP Type Check — Checks every duct, pipe, cable tray and conduit in this model against the office type catalogue: the type, and the system type for ducts and pipes.
  • Show Panel — Opens the dockable Sentinel pane, which shows the model's live rule results, the project's journey from the web, and the Doctor log.
