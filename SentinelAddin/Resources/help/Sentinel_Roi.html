ROI Dashboard

Shows the web project's ledger counts for delivery gate runs, naming renames and family heals, and prices them if the project has an ROI standard.

ROI Dashboard reads the open model's web project ledger and counts what Sentinel has done: delivery gate runs, naming renames and family heals. If the project (or its office) has an ROI standard installed (currency, hourly rate, minutes per action), each count is priced and a total is shown; without one it says money is not shown.

It also counts fixes that write ledger rows (auto-fixes, fix-in-place values written, Doctor resolutions) but does not price them, and it lists what it cannot count, such as CDE intercepts, MEP voids, BCF export and clash views, because those write no ledger row.

Every number is a count of ledger rows, so it reflects what happened on the web project, not just this model or session.

Before you start

  • The model must be bound to a web project (Project Setup). Otherwise the window reads "ROI - not bound" and nothing is read.
  • The Sentinel bridge must be reachable. If it cannot be read the window says nothing was counted and gives the reason; a failed read is never shown as zero.
  • An ROI standard installed on the project or its office to see any money figures.

How to use it

  1. Open the model bound to its web project.
  2. Click Sentinel > Standards & Build > ROI Dashboard.
  3. Revit pauses briefly while the ledger is read, then the "Return on investment" window opens.
  4. Read the lines and close the window.

What you get

  • A window headed "Return on investment" whose first line states the project and how many ledger rows were read (and if only the newest were read because the ledger holds more).
  • Lines for: Delivery gate runs, Naming renames, Family heals (each with minutes and amount if priced), Money (total, currency and hourly rate, or why it is not shown), Fixes on the ledger (not priced), and Not counted.
  • Nothing is written to the model or the ledger.

Tips and limits

"Money: not shown - roi: ..." means no ROI standard is installed for the project or its office.
A count shown as "not priced - the roi sets no minutes for it" means the ROI standard has no minutes for that action.
If the ledger is large, only the newest rows are counted and the header says so.
The window is read-only and non-modal; you can keep it open while working.

Related tools

  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
  • IFC Gate — Group of two IFC deliverable checks: Pre-Flight before you export, and Delivery Gate to certify the IFC file.
  • Naming Manager — Reviews family and type names against the office naming rules, proposes compliant names and renames only the rows you tick.
  • Heal Loaded Families — Scans the model families already in the project, auto-fixes a missing shared parameter and reports what needs a person.
  • Health Scorecard — Shows a weighted compliance score and a per-domain breakdown of the issues in the active model.
