Scan Now

Re-reads the ruleset that judges this model and runs a full compliance scan, showing the result in the Sentinel pane.

Scan Now checks the active project against the ruleset installed on the model's web project (or, failing that, its office). It first refreshes the ruleset from the web, so a rule your standards manager changed a minute ago is applied. An unchanged ruleset is a quick check, not a full download.

The command itself shows no result dialog. It opens the Sentinel pane and the scan result lands there: the compliance strip and the list of issues. Use it after a batch of modelling work, after the ruleset has been updated on the web, or when you want a fresh result.

Scan Now is read-only. It changes nothing in the model. Fixes are made from the issue list in the pane, or with Naming Manager for family and type names.

Before you start

  • A project document must be open and active. A family (.rfa) document is not scanned: Sentinel says only project documents are judged by their project's ruleset.
  • Sentinel's rule engine must be running (it starts with Revit). If it is not, the button does nothing.
  • To be judged by your project's rules, the model must be bound to its web project with Project Setup.

How to use it

  1. Open the project model you want to check and make it the active document.
  2. On the Sentinel tab, in the Validate panel, click "Scan Now".
  3. The Sentinel pane opens (or comes to the front). Wait a moment while the ruleset is re-read and the scan runs.
  4. Read the compliance strip and the issue list in the pane.

What you get

  • The Sentinel pane refreshes with the new scan: the score strip and the issues.
  • If the ruleset load produced a note, it appears in the pane's Doctor log.
  • Nothing is written to the model.

Tips and limits

A family document gives the message "A family document is not scanned — only project documents are judged by their project's ruleset."
If you switch to another project while the ruleset is loading, the new ruleset is kept for the project it belongs to and shown when you return to that project.
For a weighted score and a per-domain breakdown use Health Scorecard; to see which rules apply use Rule Set.

Related tools

  • Show Panel — Opens the dockable Sentinel pane, which shows the model's live rule results, the project's journey from the web, and the Doctor log.
  • Health Scorecard — Shows a weighted compliance score and a per-domain breakdown of the issues in the active model.
  • Rule Set — Lists the rules this model is judged by, with the ruleset's name, version and where it came from.
  • Naming Manager — Reviews family and type names against the office naming rules, proposes compliant names and renames only the rows you tick.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
