Publish tools

Publish without the pre-publish screen, the IFC certificate, and sheet and view images.

In the panel's slide-out: Publish model, Pre-publish check, Publish Sheets and Publish Views.

Tools in this group

Publish modelPublishes the whole model to the web project through the one publishing path: IFC export, pre-publish check, data requirements and naming check, then a registered version in History.Pre-publish checkExports the model to IFC (or opens an existing IFC) and certifies it against the pre-publish check rules, recording the result in the project's History.Publish SheetsRenders every Revit sheet to an image and a PDF for the web app's Sheets tab, and proposes each PDF to the project's document register.Publish ViewsLets you tick which Revit views to render as images for the web app's Views tab.

Before you start

  • A project model open and active.

How to use it

  1. Open the slide-out, click Publish tools and pick a tool.

What you get

  • The chosen tool runs as before.

Related tools

  • Publish — Publishes the model, with the pre-publish check shown first in plain words.

Ribbon tooltip

Publish without the pre-publish screen, the IFC certificate on its own, and sheet and view images for the web.
