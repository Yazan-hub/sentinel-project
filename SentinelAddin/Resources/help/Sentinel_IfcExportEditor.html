IFC Export Mapping

Set the property sets Governed Publish asks Revit's IFC exporter to write, with each property read from a Revit parameter of this model.

A client's EIR often asks for property sets of its own in the IFC. The IFC export mapping lists them: each set's name, whether it is written for each element or for its type, the IFC classes it goes on (IfcWall, IfcDoor …) and its properties — each with a data type and the Revit parameter it is read from. Governed Publish hands it to Revit's IFC exporter for every export.

The window shows the mapping in force for this model's web project: the project's own, or its office's. Revit parameter names are offered from this model; you can type another.

Before you start

  • The model is bound to its web project (Standards ▸ Project Setup).
  • To save a change you must be a lead or owner of that web project; everyone else sees the mapping read-only.

How to use it

  1. Click Standards ▸ IFC Export Mapping under Sentinel > Standards & Build.
  2. Name the mapping and choose whether the exporter also writes the IFC common property sets.
  3. Add or pick a property set: its name (letters, digits and _), for each element or for its type, the IFC classes it goes on, and its properties (name, data type, Revit parameter).
  4. Choose This project, or Every project in the office, and press Save. The window names the version saved; it is recorded in the ledger.

What you get

  • A new version of the IFC export mapping on the project or its office, with a ledger row naming who saved it. The next Governed Publish uses it.

Tips and limits

A blank Revit parameter means the parameter with the property's own name.
If someone saved a newer mapping while the window was open, Save refuses and asks you to reopen the window.
In the web app, Project Settings ▸ Standards in force names this window on the ifc_export row.

Related tools

  • Governed Publish — Publishes the whole model to the web project through the one governed path: IFC export, delivery gate, IDS and naming check, then a registered version on the ledger.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.

Ribbon tooltip
