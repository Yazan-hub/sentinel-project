Publish

A drop-down group holding Publish Sheets and Publish Views, which send drawing images to the web app outside the governed IFC path.

The Publish drop-down holds two tools that push what IFC cannot carry: Publish Sheets renders every Revit sheet, and Publish Views renders the views you tick. Both write images and a manifest under %AppData%\Sentinel, keyed by the model's name, for the Sentinel bridge to serve to the web app's Sheets and Views tabs.

These are not the governed model publish. The model itself goes to the project only through Governed Publish (or on save when the project's publish standard says auto). Publish Sheets additionally proposes each sheet's PDF to the project's document register; Publish Views does not touch the ledger.

Use the group when reviewers need to see the actual drawings or saved views in the web app next to the 3D model.

Tools in this group

Publish SheetsRenders every Revit sheet to an image and a PDF for the web app's Sheets tab, and proposes each PDF to the project's document register.Publish ViewsLets you tick which Revit views to render as images for the web app's Views tab.

Before you start

  • See the individual tools: both need an open project bound to a web project via Project Setup.

How to use it

  1. Click the Publish drop-down arrow under Sentinel > Publish.
  2. Choose Publish Sheets to render every sheet, or Publish Views to pick which views to render.

What you get

  • Images and a manifest under %AppData%\Sentinel\sheets or %AppData%\Sentinel\views, in a folder named after the model, served by the bridge to the web app.

Tips and limits

Each run replaces the model's previous folder, so sheets or views that were deleted, renamed or unticked disappear from the web app.
The images are keyed by model name, not by web project.

Related tools

  • Publish Sheets — Renders every Revit sheet to an image and a PDF for the web app's Sheets tab, and proposes each PDF to the project's document register.
  • Publish Views — Lets you tick which Revit views to render as images for the web app's Views tab.
  • Governed Publish — Publishes the whole model to the web project through the one governed path: IFC export, delivery gate, IDS and naming check, then a registered version on the ledger.

Ribbon tooltip

Sheets and views for the web app's Sheets and Views tabs — images keyed by model name under %AppData%, outside the governed IFC path (no version, no verdict). The model itself publishes only through Governed Publish, or on save when the project's publish@n says auto: true (the pane's strip names it).
