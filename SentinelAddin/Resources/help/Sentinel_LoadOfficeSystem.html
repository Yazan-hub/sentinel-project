Apply Standard

Loads a saved standards pack from disk and lets you build it into the open model, the golden-to-blank round trip.

Apply Standard opens a standards pack file (the kind Build Office System or the review window's Save pack writes), shows its contents in the same review window, and builds the ticked items into the model that is active when you start. Use it to bring the office worksets, shared parameters and rules into a new or blank model.

The build is the same as in Build Office System: items that already exist are skipped, the whole build is one Undo entry, and ticked worksets and naming rules are installed into the web project's ruleset when the model is bound.

Before you start

  • A Revit model open (the target).
  • A standards pack file (.json), normally in %AppData%\Sentinel\packs.
  • For the ruleset install, the model must be bound to a web project (Project Setup); otherwise the model is still built and the report says no ruleset was installed.
  • Worksets need a workshared target model; otherwise they are skipped with a message.
  • View templates and browser schemes in the pack are copied from the pack's source model, which must be open in the same Revit session; otherwise they are skipped with a message naming the model to open.

What you provide

Load Sentinel Standards Pack (file dialog)
Choose a .json standards pack. The dialog opens in %AppData%\Sentinel\packs when that folder exists.
Review window tree and buttons
Tick the items to build, then Build ticked items; the window also offers Save pack, ISO 19650 check, Send office snapshot to Sentinel and Install catalogue on office (see Build Office System).

How to use it

  1. Open or create the target model and bind it to its web project (Project Setup) if you want the ruleset installed.
  2. Click Sentinel > Standards > Apply Standard.
  3. Pick the pack file in the "Load Sentinel Standards Pack" dialog.
  4. In the review window, tick or untick items. The status line reads "N item(s) from '<file>'. Tick items, then Build into '<model>'."
  5. Click Build ticked items and read the Created, Skipped and Failed report and the ruleset install result.

What you get

  • Worksets, shared-parameter bindings, view templates and browser schemes added to the active model as one Undo entry named "Apply standard".
  • Existing items are listed as skipped.
  • The project's ruleset gets a new version with the pack's worksets and naming rules when the model is bound and the bridge answers.
  • One "Apply Standard" row on the project ledger when Revit kept the build and something was created.

Tips and limits

"Could not read the standards pack" means the file is not valid pack JSON; the reason is shown.
"The selected file is not a valid standards pack" means the file was empty or not a pack.
The type catalogue shown in the window is reference only; nothing in it is built.
The Send office snapshot button needs a pack that came from a model; a pack with no source model says to extract from a template first.
If you switch to another model before pressing Build, the build refuses and changes nothing.

Related tools

  • Build Office System — Reads the office standard out of the open "golden" model, lets you review and tick it, then builds it into this model and into the project's ruleset.
  • Ingest Docs — Reads office-standards documents with a local language model and proposes worksets, shared parameters and naming rules for you to review.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
  • Rule Set — Lists the rules this model is judged by, with the ruleset's name, version and where it came from.
  • Naming Manager — Reviews family and type names against the office naming rules, proposes compliant names and renames only the rows you tick.
