Clash Register

Shows, read-only, the project's team-wide clash register recorded on the web: how many clashes there are, their status counts, and the biggest by volume.

Clash Register brings the web's clash picture into Revit. The clashes are recorded on the web when someone runs Coordination ▸ Clash ▸ Run with two or more models loaded; the register tracks each clash through the status lifecycle raised, reviewed, approved and resolved. The button reads that register for the model's web project and shows it in a dialog titled "Sentinel — Clash Register".

The dialog gives the total number of clashes recorded, a one-line count by status (for example "3 raised · 1 reviewed"), and a list of up to the 12 biggest clashes by shared volume, each as "[status] label — volume m³". It is purely informational: it never changes the model or the register, and the web side owns the clash lifecycle.

Before you start

  • The open model must be bound to a web project (Sentinel ▸ Project Setup). Otherwise: "This model is not bound to a web project — Sentinel ▸ Project Setup."
  • You must be signed in; if the bridge refuses the call you see "The bridge refused this call for project '<key>': signed out — Sentinel ▸ Sign in."
  • The Sentinel bridge must be running. If not: "Couldn't reach the Sentinel bridge / CDE for project '<key>'" with a hint to start it.
  • Clashes must already have been run and recorded on the web; otherwise there is nothing to show.

How to use it

  1. On the Sentinel tab, in the Coordinate panel, open the "Clash" drop-down and click "Clash Register".
  2. Read the dialog: the total, the status counts, and the biggest clashes by volume.
  3. Close the dialog; go to the web (Coordination ▸ Clash) to review or change a clash's status.

What you get

  • A single information dialog. Nothing is written to the model, the web or the ledger.
  • If the register is empty the dialog says "No clashes recorded for this project yet." and explains how to populate it (load 2 or more models on the web and run Coordination ▸ Clash ▸ Run).

Tips and limits

Volumes under 0.01 m³ are shown in scientific notation.
Only the 12 biggest clashes are listed; the web shows the full register.
A clash with no status is counted as "unknown" in the status line and shown as "?" in the list.
This is not the same as Clash Manager: Clash Manager detects clashes live in this Revit model; Clash Register reads what the team has recorded on the web.

Related tools

  • Clash Manager — Detects clashes between linked MEP/IFC models and your native structure, grades them by severity, and lets you open a coloured 3D clash view or export them to BCF.
  • BCF Issues — Shows the coordination issues raised on the web (BCF), jumps Revit to each issue's element and camera, and lets you raise new issues from your Revit selection.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
  • Sign in — Signs you in with your Sentinel account so everything Revit sends to the project carries your name.
