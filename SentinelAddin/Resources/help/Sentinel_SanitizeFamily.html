Sanitize .rfa

Audits a family file (.rfa) for heavy geometry, nested CAD, missing shared parameters and unnamed types, and loads it into the project only if it passes.

Sanitize .rfa opens the family file you choose, in the background, and runs four checks. Heavy geometry: more than 150 solids is a fail. Nested CAD: any imported CAD in the family is a fail, with advice to explode and redraw it. Required shared parameter: the office's description parameter must be present in the family. Type sanity: every family type must have a real name (not blank, not a single character).

If the family passes and a project is open, it is loaded into that project, replacing a family of the same name already there. If it fails, it is not loaded and the dialog lists every issue.

If the model's ruleset has no office code, the shared parameter check is skipped and a note is written to the pane's Doctor log. The other three checks still run.

Before you start

  • A project document should be active to load into. If none is (or a family document is active), the family is only scanned, not loaded: the result then says it passed with no target document to load into.
  • The file must be a Revit family (.rfa).
  • For the shared parameter check, the ruleset must carry an office code.

What you provide

Select family to sanitize and load (file dialog)
Pick one .rfa file. The file must exist.

How to use it

  1. Make the project that should receive the family the active document.
  2. On the Sentinel tab, in the Validate panel, open "Family Health" and click "Sanitize .rfa".
  3. Choose the .rfa file in the dialog "Select family to sanitize and load".
  4. Wait for the audit; the family is opened and closed in the background.
  5. Read the dialog "Sentinel — Family Sanitation" and click Close.

What you get

  • A dialog headed "Family passed and was loaded", "Family passed (no target document to load into)" or "Family failed sanitation — NOT loaded". Below it: the file name, the solid count against the budget of 150, the number of nested CAD imports, and the list of issues.
  • On a pass, the family is loaded into the project.
  • Nothing is sent to the web ledger by this tool.

Tips and limits

Fix geometry and CAD problems in the Family Editor; Sentinel will not do these for you.
A missing shared parameter is reported here; Heal Loaded Families can add it once the family is in the project.
If the project in front is not the one you started on when the job runs, Sentinel asks you to switch back and loads nothing.

Related tools

  • Heal Loaded Families — Scans the model families already in the project, auto-fixes a missing shared parameter and reports what needs a person.
  • Naming Manager — Reviews family and type names against the office naming rules, proposes compliant names and renames only the rows you tick.
  • Show Panel — Opens the dockable Sentinel pane, which shows the model's live rule results, the project's journey from the web, and the Doctor log.

Ribbon tooltip

Audit an .rfa (geometry budget, nested CAD, shared parameters) before loading it.
