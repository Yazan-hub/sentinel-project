PC Settings

Set this PC's own Sentinel settings in a window — the bridge, the sign-in, the local AI and Ghost Builder's folders — and test each connection.

Some settings belong to a PC, not to a project: where this PC finds the Sentinel bridge, how it signs in, which local AI model it uses and where Ghost Builder finds its family library and layer mapping file. PC Settings shows them as plain fields. A model never carries them, and nobody needs to edit a file.

Save changes only the fields you changed and keeps a copy of the old settings beside them, so nothing else on this PC is lost. This PC's shared token and the sign-in key are never shown: the window only says whether one is set.

Before you start

  • None. The window opens with or without a model.

What you provide

Bridge address
Where this PC finds the Sentinel bridge. On the PC that runs the bridge it is http://localhost:4100; elsewhere an https address. Test says whether a bridge answers.
This PC's shared token
The bridge's machine credential. Leave blank to keep the saved one, type a new one to replace it, or tick Remove it. It works only with the bridge on this PC; people elsewhere sign in instead.
Sign-in address and Sign-in key
Where Revit signs people in (the same account as the web app). Test says whether you are signed in and the sign-in is still valid. The key is never shown; leave it blank to keep it.
Issues: only model id
Lists only one model's issues in the Issues window; blank lists every model's.
Local AI address
The Ollama address Ghost Builder, Photo Massing and Ingest Docs use. Test says whether it answers and whether Ghost Builder's model and the photo model are installed on it.
Allow a model off this PC
Off by default: drawings and photos stay on this PC. Tick it only to use a model at an https address elsewhere.
Ghost Builder model and Photo model
The model names Ghost Builder and Photo Massing ask for.
Family library folder and Layer mapping file
Optional. Browse… picks them. The layer mapping file must sit in the add-in's folder or in Sentinel's schemas folder.

How to use it

  1. Click Standards ▸ PC Settings under Sentinel > Standards & Build.
  2. Change the fields you need. Press Test beside a connection to check it; the answer appears under the field.
  3. Press Save. The window says which settings were saved and where the old ones were kept.

What you get

  • This PC's settings are saved; Sentinel's tools use them from their next run.
  • A copy of the previous settings is kept beside them, named with the date and time.

Tips and limits

If Save is refused, the window says why in words — for example a plain http address on another PC, or a shared token with a bridge that is not on this PC.
The drawings folder Ghost Builder reads is set per model in Standards ▸ Project Setup.
An Issues window that is already open keeps the old bridge address until you open it again.

Related tools

  • Sign in — Signs you in with your Sentinel account so everything Revit sends to the project carries your name.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
  • 2 · Ghost Builder — Builds LOD 200 Revit geometry (walls, floors, doors, windows and more) from a 2D DWG plan, mapping CAD layers to Revit types by the project's standards, after you review and tick what to build.
