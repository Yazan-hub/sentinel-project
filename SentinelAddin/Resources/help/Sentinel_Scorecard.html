Health Scorecard

Shows a weighted compliance score and a per-domain breakdown of the issues in the active model.

Health Scorecard runs a full scan of the active model and turns the list of issues into one executive number: a weighted rule score with a letter grade (A to F), the rule pass rate, and a list of issues by rule domain (the letters before the dash in a rule id, for example NAM or IFC).

The weighting follows how strict each rule is: a BLOCK issue counts 8, REQUEST 4, WARN 2 and MONITOR 0.5. One blocking issue therefore hurts the score far more than several informational ones. The dialog also prints the formula, so the number can be explained to a project manager.

The dialog opens with "Judged by" followed by the name of the ruleset that was used. If no ruleset judged the model, it says the model is "Not scored" and gives no grade, rather than showing a misleading 100.

Before you start

  • A document must be open and active.
  • Sentinel's rule engine must be running.
  • For a real score, the model's web project (or office) needs an installed ruleset, and the model must be bound via Project Setup.

How to use it

  1. Make the model you want to measure the active document.
  2. On the Sentinel tab, in the Validate panel, click "Health Scorecard".
  3. Read the dialog "Sentinel — Health Scorecard" and click Close.

What you get

  • A dialog with: the ruleset that judged the model, the model name and time, the headline (weighted rule score, grade, rule pass rate, number of open issues and domains), the scoring formula, and one line per domain with its issue count and penalty.
  • Nothing is written to the model.

Tips and limits

The two figures differ on purpose: the weighted score reflects severity; the rule pass rate is simply checks passed divided by checks run. MONITOR rules are not scored in the pass rate.
"Not scored" means no ruleset judged the model, or no rule was left to evaluate. Install or fix the ruleset, then run it again.
The scorecard takes a fresh scan each time you click it.

Related tools

  • Scan Now — Re-reads the ruleset that judges this model and runs a full compliance scan, showing the result in the Sentinel pane.
  • Rule Set — Lists the rules this model is judged by, with the ruleset's name, version and where it came from.
  • Show Panel — Opens the dockable Sentinel pane, which shows the model's live rule results, the project's journey from the web, and the Doctor log.
  • ROI Dashboard — Shows the web project's ledger counts for delivery gate runs, naming renames and family heals, and prices them if the project has an ROI standard.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
