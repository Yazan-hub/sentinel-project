Checks

The single checks that Check runs together.

In the panel's slide-out (the arrow under the Sentinel panel): Scan Now, Health Scorecard, Rule Set, IFC Pre-Flight, MEP Type Check, Naming Manager and the family tools.

Tools in this group

Scan NowRe-reads the ruleset that judges this model and runs a full compliance scan, showing the result in the Sentinel pane.Health ScorecardShows a weighted compliance score and a per-domain breakdown of the issues in the active model.Rule SetLists the rules this model is judged by, with the ruleset's name, version and where it came from.IFC Pre-FlightAudits the model before IFC export for missing 'Export to IFC As' mappings and for the properties the delivery contract requires.MEP Type CheckChecks every duct, pipe, cable tray and conduit in this model against the office type catalogue: the type, and the system type for ducts and pipes.Naming ManagerReviews family and type names against the office naming rules, proposes compliant names and renames only the rows you tick.Sanitize .rfaAudits a family file (.rfa) for heavy geometry, nested CAD, missing shared parameters and unnamed types, and loads it into the project only if it passes.Heal Loaded FamiliesScans the model families already in the project, auto-fixes a missing shared parameter and reports what needs a person.

Before you start

  • A project model open and active.

How to use it

  1. Open the slide-out, click Checks and pick a tool.

What you get

  • The chosen tool runs as before.

Related tools

  • Check — Checks the model against the project standards and groups what to fix.

Ribbon tooltip

The single checks Check runs together, plus the score, the rules in force and the family tools.
