Modelling Guideline

Set the office's modelling guideline in a window: the rules that type what Sentinel builds and promotes, the sheets Annotate makes and the worksets new elements go on.

The modelling guideline tells Sentinel which family and type to use. For each category (walls, floors, doors, stairs …) it holds rules in order — when a CAD layer, a level, a discipline or a parameter matches, use this family and this type (or a type pattern such as EXT_{thickness} mm) — and a default for when no rule matches. A rule with more conditions is tried before one with fewer; between rules with as many conditions, the higher one wins. Ghost Builder, Shell a Mass and Promote read it.

The window shows the guideline in force for this model's web project: the project's own, or its office's. Families, types, levels, title blocks and worksets are offered from this model; you can type a name that is not in it. What the window does not show (view standards, graphics and any other part of the guideline) is kept as it is when you save.

Before you start

  • The model is bound to its web project (Standards ▸ Project Setup).
  • To save a change you must be a lead or owner of that web project; everyone else sees the guideline read-only.

How to use it

  1. Click Standards ▸ Modelling Guideline under Sentinel > Standards & Build.
  2. Pick a category, or add one. Change its rules: the condition (CAD layer, level, discipline, parameters such as Material = STONE) and what to use (family, type or type pattern; the run width for stairs). Use ↑ and ↓ to order rules with as many conditions, and fill the default.
  3. Optionally set the sheets (title block, number and name patterns with {level}, {use}, {prefix}, {n}) and the workset for each category's new elements.
  4. Choose This project, or Every project in the office, and press Save. The window names the version saved; it is recorded in the ledger.

What you get

  • A new version of the guideline on the project or its office, with a ledger row naming who saved it. Sentinel uses it from the next command you run.

Tips and limits

A blank field is not a condition. A rule with no condition at all is refused: make it the category's default instead.
If someone saved a newer guideline while the window was open, Save refuses and asks you to reopen the window, so nothing is overwritten unseen.
In the web app, Project Settings ▸ Standards in force names this window on the guideline row.

Related tools

  • 2 · Ghost Builder — Builds LOD 200 Revit geometry (walls, floors, doors, windows and more) from a 2D DWG plan, mapping CAD layers to Revit types by the project's standards, after you review and tick what to build.
  • 4 · Promote (DD) — Promotes the model's walls, floors, roofs, ceilings, doors and windows to design-development types by the office guideline, type catalogue and LOD matrix, filing the changes for review.
  • 3 · Annotate Views — Creates the work-in-progress plan views the guideline prescribes for each level, pins levels and grids, and optionally copies view templates and makes sheets with tags.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
