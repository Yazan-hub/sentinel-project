2 · Ghost Builder

Builds LOD 200 Revit geometry (walls, floors, doors, windows and more) from a 2D DWG plan, mapping CAD layers to Revit types by the project's standards, after you review and tick what to build.

Ghost Builder takes a 2D plan drawing and proposes a model from it. It first imports the drawing for the run, reads the CAD layers and maps each layer to what it represents (walls, doors, windows, floors and so on). The mapping follows the project's layers standard first, then what it remembered for this project, then labelled heuristics, and only for what is left a language model that runs on your own PC. Nothing the model suggests is pre-ticked.

You then get a review window that lists the proposal by layer, with how many elements each layer holds, a type drop-down where the proposal is wrong, an option to ignore a layer, and a "Build on level:" box. Nothing has been built at that point. When you press "Build ticked layers ▶" the build is filed on the project's ledger as changesets from the drawing and placed in one step, with every element stamped with its source drawing and checksum. Walls are typed by the project's guideline and type catalogue; a type that is not installed is reported as a gap.

Revit stays usable while it works: the language model call and the reading of the standards run in the background, with a progress window you can cancel. Photos in the project's evidence pack, if any, and documents in the Ghost source folder are used as extra hints for the layer mapping only.

Before you start

  • A Revit project open, in a plan view of the level you build on. Section, elevation, 3D and drafting views are refused because the imported drawing would lie in the wrong plane. Open a floor plan and run again.
  • A 2D DWG: either DWG or DXF files in the Ghost source folder (Project Setup), or a DWG import already in the model, which you pick on screen ("Select a 2D CAD (DWG) import to build from.").
  • The layers standard, guideline and type catalogue installed on the web project or its office, with the model bound via Project Setup. If the guideline cannot be read, the run stops. A standard that is not installed reads "none" in the review header. A model not bound to a project runs the build as a local changeset with no ledger.
  • The model should come from the office template: if it holds none of the office types in the installed catalogue, the run is refused and says so.
  • Ollama running on this PC with the Ghost model pulled. If it cannot be reached you are told to start Ollama and pull the model. Evidence photos are read by a vision model only if the model runs on this PC.
  • Not in a design option. If the mapping schema or family library folder named in this PC's config cannot be found, the tool tells you which one to fix or clear.

What you provide

Choose a drawing ("Sentinel — Ghost Builder: choose a drawing")
Shown when the Ghost source folder holds DWG/DXF files. Pick one and press "Use selected drawing ▶", or "Pick from model…" to use an import already in the model.
The drawing's units:
"as the file says", millimetres, centimetres, metres, inches or feet. Set it if the file header is wrong.
Layer rows (tick boxes)
One per mapped CAD layer. Tick the layers to build. Each row shows how it was mapped and a confidence score.
Type drop-down / (ignore)
Change the type for a layer or set it to (ignore) where the proposal is wrong. Your picks are remembered for this project's next run.
Build on level:
The level the elements are placed on. It opens on the level at the drawing's elevation, else the active plan's level, else the lowest.

How to use it

  1. Open a floor plan of the level you build on.
  2. Click Model from Drawings, then "2 · Ghost Builder".
  3. If drawings are listed, select one, set "The drawing's units:" and press "Use selected drawing ▶". Otherwise select the CAD import in the view.
  4. Wait while the standards are read, any photos and documents are used as hints, and the layers are mapped. Press Esc or Cancel in the progress window to stop.
  5. In "Sentinel — Ghost Builder: review the build proposal", tick the layers to build, change types or choose (ignore) where the proposal is wrong, and check "Build on level:".
  6. Press "Build ticked layers ▶".
  7. If the build would add elements that your sync-blocking rules would stop, you are asked whether to place it anyway; going back keeps the review open and places nothing.
  8. Read the summary dialog.

What you get

  • Elements are placed on the chosen level in one Undo entry, each stamped as from the source drawing. The imported DWG made for the run is removed again inside that Undo; an import you picked from the model is kept.
  • The summary names the standards used, how many elements were placed, how walls were typed (by the guideline, by the layer mapping, by you, or left as a gap), what was skipped and why, any types or families added, Revit warnings and the ledger line.
  • The build is also filed as changesets with source dwg on the project's ledger.

Tips and limits

Cancel, or closing the review without building, writes nothing and removes the imported drawing.
Doors and windows are only placed on a wall of the same build; the summary counts those skipped because no single straight wall was close enough, and those where the wall line stops short of the opening.
Run Datum from Drawings first so the build has real levels to host on.
Ghost Builder places directly after your Build click. Use Provenance on a built element to see the drawing and layer it came from.

Related tools

  • 1 · Datum from Drawings — Reads the levels from a section drawing and the grids from a plan drawing and creates them in the model, so that everything modelled afterwards sits on real heights and a real column grid.
  • 2c · Shell a Mass — Turns a selected mass into typed walls, a floor per level and a flat roof, one storey at a time, filed for review as changesets.
  • 3 · Annotate Views — Creates the work-in-progress plan views the guideline prescribes for each level, pins levels and grids, and optionally copies view templates and makes sheets with tags.
  • 4 · Promote (DD) — Promotes the model's walls, floors, roofs, ceilings, doors and windows to design-development types by the office guideline, type catalogue and LOD matrix, filing the changes for review.
  • 5 · Provenance — Shows where the selected element came from: Sentinel's provenance stamp in plain words.
  • Standards — A drop-down group for binding a model to its web project, signing in, and building, applying or ingesting office standards.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
