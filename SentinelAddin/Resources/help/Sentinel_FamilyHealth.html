Family Health

Group of two family hygiene tools: audit an .rfa before it enters the project, or heal families already loaded.

Family Health is a drop-down on the Validate panel. "Sanitize .rfa" audits a family file on disk and loads it into the project only if it passes. "Heal Loaded Families" scans the families already in the project and automatically fixes what can be fixed safely.

Both look for the same problems: heavy geometry, nested CAD imports, a missing required shared parameter and unnamed family types. Anything that needs a human decision about geometry or CAD is reported and left untouched.

Use Sanitize .rfa as a gate on incoming content, and Heal Loaded Families as a clean-up of what is already in the model.

How to use it

  1. On the Sentinel tab, in the Validate panel, open the "Family Health" drop-down.
  2. Choose "Sanitize .rfa" or "Heal Loaded Families".

Related tools

  • Sanitize .rfa — Audits a family file (.rfa) for heavy geometry, nested CAD, missing shared parameters and unnamed types, and loads it into the project only if it passes.
  • Heal Loaded Families — Scans the model families already in the project, auto-fixes a missing shared parameter and reports what needs a person.
  • Naming Manager — Reviews family and type names against the office naming rules, proposes compliant names and renames only the rows you tick.
  • Build Office System — Reads the office standard out of the open "golden" model, lets you review and tick it, then builds it into this model and into the project's ruleset.
