Sentinel for Revit

Sentinel governs a Revit model against its web project: the rules, standards and delivery contract installed there judge the model, every governed action is recorded on the project ledger, and AI proposals wait for a person to approve them.

Hover any Sentinel button on the ribbon and press F1 to open its page here. Use the tree on the left, or the filter box, to move between tools.

Coordinate

Show PanelOpens the dockable Sentinel pane, which shows the model's live rule results, the project's journey from the web, and the Doctor log.Change RequestsLists the change requests waiting for a coordinator and lets a lead or owner approve or reject each one.BCF IssuesShows the coordination issues raised on the web (BCF), jumps Revit to each issue's element and camera, and lets you raise new issues from your Revit selection.ClashA drop-down group holding the two clash tools: Clash Manager (run clash detection in this model) and Clash Register (read the team-wide clash register from the web).Clash ManagerDetects clashes between linked MEP/IFC models and your native structure, grades them by severity, and lets you open a coloured 3D clash view or export them to BCF.Clash RegisterShows, read-only, the project's team-wide clash register recorded on the web: how many clashes there are, their status counts, and the biggest by volume.Review FlagOne-time project setup: creates the ZZZ_ReviewStatus flag parameter on Views, Sheets, Levels and Grids so pending changes can be grouped in the Project Browser.Review AI ProposalsLets you review AI-proposed model changes: see the referee's verdict per element, tick what you accept, and apply exactly that to the model in one Undo step.

Validate

Scan NowRe-reads the ruleset that judges this model and runs a full compliance scan, showing the result in the Sentinel pane.Health ScorecardShows a weighted compliance score and a per-domain breakdown of the issues in the active model.Rule SetLists the rules this model is judged by, with the ruleset's name, version and where it came from.IFC GateGroup of two IFC deliverable checks: Pre-Flight before you export, and Delivery Gate to certify the IFC file.IFC Pre-FlightAudits the model before IFC export for missing 'Export to IFC As' mappings and for the properties the delivery contract requires.IFC Delivery GateExports the model to IFC (or opens an existing IFC) and certifies it against the delivery contract, recording the verdict on the project ledger.Family HealthGroup of two family hygiene tools: audit an .rfa before it enters the project, or heal families already loaded.Sanitize .rfaAudits a family file (.rfa) for heavy geometry, nested CAD, missing shared parameters and unnamed types, and loads it into the project only if it passes.Heal Loaded FamiliesScans the model families already in the project, auto-fixes a missing shared parameter and reports what needs a person.MEP OpeningsFinds where linked MEP crosses native walls, floors and structural framing and offers to place tracked provision-for-void markers or export a BCF.MEP Type CheckChecks every duct, pipe, cable tray and conduit in this model against the office type catalogue: the type, and the system type for ducts and pipes.Naming ManagerReviews family and type names against the office naming rules, proposes compliant names and renames only the rows you tick.

Publish

Governed PublishPublishes the whole model to the web project through the one governed path: IFC export, delivery gate, IDS and naming check, then a registered version on the ledger.PublishA drop-down group holding Publish Sheets and Publish Views, which send drawing images to the web app outside the governed IFC path.Publish SheetsRenders every Revit sheet to an image and a PDF for the web app's Sheets tab, and proposes each PDF to the project's document register.Publish ViewsLets you tick which Revit views to render as images for the web app's Views tab.

Standards & Build

StandardsA drop-down group for binding a model to its web project, signing in, and building, applying or ingesting office standards.Project SetupBinds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.Sign inSigns you in with your Sentinel account so everything Revit sends to the project carries your name.PC SettingsSet this PC's own Sentinel settings in a window — the bridge, the sign-in, the local AI and Ghost Builder's folders — and test each connection.Build Office SystemReads the office standard out of the open "golden" model, lets you review and tick it, then builds it into this model and into the project's ruleset.Apply StandardLoads a saved standards pack from disk and lets you build it into the open model, the golden-to-blank round trip.Ingest DocsReads office-standards documents with a local language model and proposes worksets, shared parameters and naming rules for you to review.Modelling GuidelineSet the office's modelling guideline in a window: the rules that type what Sentinel builds and promotes, the sheets Annotate makes and the worksets new elements go on.IFC Export MappingSet the property sets Governed Publish asks Revit's IFC exporter to write, with each property read from a Revit parameter of this model.ProtectionChoose what no changeset may edit — grids, levels, structure and chosen worksets — for this project or the whole office.Model from DrawingsThe Model from Drawings pulldown groups the seven tools that take a project from drawings or photos to a governed Revit model, in the order they are meant to be run.1 · Datum from DrawingsReads the levels from a section drawing and the grids from a plan drawing and creates them in the model, so that everything modelled afterwards sits on real heights and a real column grid.2 · Ghost BuilderBuilds LOD 200 Revit geometry (walls, floors, doors, windows and more) from a 2D DWG plan, mapping CAD layers to Revit types by the project's standards, after you review and tick what to build.2b · Photo MassingEstimates a building's storeys and proportions from the project's evidence-pack photos, lets you scale and correct the numbers, and files the missing levels and a mass for review.2c · Shell a MassTurns a selected mass into typed walls, a floor per level and a flat roof, one storey at a time, filed for review as changesets.3 · Annotate ViewsCreates the work-in-progress plan views the guideline prescribes for each level, pins levels and grids, and optionally copies view templates and makes sheets with tags.4 · Promote (DD)Promotes the model's walls, floors, roofs, ceilings, doors and windows to design-development types by the office guideline, type catalogue and LOD matrix, filing the changes for review.5 · ProvenanceShows where the selected element came from: Sentinel's provenance stamp in plain words.ROI DashboardShows the web project's ledger counts for delivery gate runs, naming renames and family heals, and prices them if the project has an ROI standard.
