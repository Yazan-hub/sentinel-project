Protection

Choose what no changeset may edit — grids, levels, structure and chosen worksets — for this project or the whole office.

Protection is the list of things Sentinel never changes on its own. When a changeset — from an AI agent, the web or Promote — would edit an existing grid, level, structural element or an element on a protected workset, that row is kept as it stands and the reason is shown; the rest of the changeset is still applied. New elements are not affected.

The window shows the policy in force: one saved for this project, one saved for its office, or Sentinel's built-in default when none is saved. The built-in default protects grids, levels, the project base point and survey point, structural columns, framing and foundations, walls and floors marked Structural, and the Shared Levels and Grids workset.

Before you start

  • The model is bound to its web project (Standards ▸ Project Setup).
  • To save a change you must be a lead or owner of that web project; everyone else sees the policy read-only.

How to use it

  1. Click Protection under Sentinel > Standards & Build.
  2. Tick what must never be edited by a changeset; tick this model's worksets, or type other workset names in the box (one per line; * means anything).
  3. Choose This project, or Every project in the office.
  4. Press Save. The window says which version was saved; it is recorded in the ledger and used for the next changeset you apply.

What you get

  • A new version of the protection policy on the project or its office, with a ledger row naming who saved it.

Tips and limits

A project's own policy wins over the office's. The window says so when you save for the office while this project has its own.
Reset to the built-in default fills the form with the default; nothing changes until you press Save.
To change a protected element, edit it by hand in Revit, or save a looser policy first.

Related tools

  • Standards — A drop-down group for binding a model to its web project, signing in, and building, applying or ingesting office standards.
  • Review AI Proposals — Lets you review AI-proposed model changes: see the referee's verdict per element, tick what you accept, and apply exactly that to the model in one Undo step.
  • Project Setup — Binds the open model to its web project and sets the project code, ghost source folder and Revit Doctor option.
