        What this tool can and cannot see

        This reads words. It looks for a named owner, a date or milestone, a stated purpose, and enforceable language — the four things a clause needs before it can manage anything. A clause that reads well will pass here even if nothing in the world enforces it.

        That gap is the point. Sentinel's real check binds each clause to live project data — the CDE, the IDS specification, the delivery plan — and returns met, violated with the failing containers named, or not checkable with the reason it cannot be judged. It never reports a pass for something it did not measure. Text can be graded; only a bound clause can be enforced.
